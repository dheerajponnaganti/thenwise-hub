# Security

The Hub shows a team's shared memory, so we treat security reports first.

## Report a problem

Report it privately through a [security advisory](https://github.com/dheerajponnaganti/thenwise-hub/security/advisories/new). Please do not open a public issue. A problem in the team server or its API goes to the [thenwise advisories](https://github.com/dheerajponnaganti/thenwise/security/advisories/new).

Include what you found, the steps to see it, the Hub version and the thenwise server version.

## What counts

- Shared text that runs as code in the browser, in a card, a volume, a search snippet or a name.
- A token that leaks into a URL, a log, the page or storage another site can read.
- A screen that shows or changes something the signed-in role should not reach.

## Supported versions

Fixes land in the latest release.
